# DESIGN_INTELLIGENCE — ذكاء مِرسم: ماذا يقيس، ماذا يقرّر

> هذا مستند تشغيل الفكرة الأساسية لمِرسم: **مخرج قابل للقياس لا صورة مولَّدة.** كل ادعاء فيه مُتحقَّق منه في المتصفح (خط أساس + مصفوفة 60 تركيبة).

## 1. المبدأ الفاصل: قياس ← حكم

| الشدة | المعنى | أثرها على النتيجة |
|---|---|---|
| `NOTE` | معلومة أو ذوق معلَّم — **لا يكسر أبدًا** | تظهر في اللوحة مع السبب |
| `WARN` | خلل قابل للإصلاح الآلي | يدخل `FIXABLE` ويُصلَح في الحلقة |
| `FAIL` | كسر بنيوي (تجاوز قماش · تداخل · SVG تالف) | يُعرَض باسم العنصر والبكسلات — لا يُخفى |

**الذوق لا يُقدَّم كحقيقة:** كل ملاحظة جمالية معلَّمة `NOTE`، وكل رقم في لوحة القياسات مأخوذ من مربّعات الرسم نفسها.

## 2. حلقة التحسين `runLoop`

```
makePlan → applyKnowledge → applyOverrides → renderSVG → svgToCanvas
     ▲                                                     │
     └────────── applyFixes ◄── analyze ◄──────────────────┘
                  (حتى 3 محاولات · قفل المصمّم يُحترم · توقّف صادق)
```

- **قياس حقيقي:** النص يُقاس بـ`measureText` على سطور مكسورة فعليًا (`wrapLines`) بخط مُسجَّل؛ الصناديق من `typeBBox` — **مصدر واحد** يستعمله المخطّط والفحص ولوحة القياسات.
- **`locked()` قبل كل فرع إصلاح:** تعديل المصمّم (قفل/ترتيب/موضع/لون…) يعلو على الإصلاح الآلي دائمًا، مع رسالة صادقة: «مقفل: … تُرك كما هو — ألغِ القفل ليُصلَح تلقائيًا».
- **توقّف صادق لا فوز صامت:**
  - `MAX_RETRIES` = انتهت المحاولات وبقي خلل (يُعرض مع الفشل الظاهر).
  - `UNIMPROVABLE` = لا حركة ممكنة (كل محاولة إصلاح مقطوعة بقفل) — النتيجة تُكتب كما هي.
- **تكرار idempotent:** `applyOverrides` يحسب الموضع من قاعدة مُخطَّطة (`base.pos`)، فيُستدعى مرتين داخل الحلقة بلا تضاعف.

## 3. الفحوصات — 18 فحصًا

| id | الفحص | الشدة | الحدّ |
|---|---|---|---|
| `text-overflow` | نص خارج القماش / داخل منطقة الأمان | FAIL / WARN | قياس هندسي لكل كتلة نص مرئية — باسم العنصر وعدد البكسلات |
| `layer-overlap` | تداخل طبقات (كلمات↔كلمات · كلمات↔QR · كلمات↔أيقونة) | WARN | تقاطع ≥25% من الأصغر **و** ≥600px² بعد إقصاء 10% من كل صندوق (الملامسة الشعرية لا تُبلَّغ) |
| `low-contrast` | تباين النص مع السطح | WARN | < 4.5:1 (WCAG AA) |
| `weak-hierarchy` | تدرّج أحجام ضعيف | WARN | نسبة العنوان < 1.6× |
| `clutter` | تغطية سطحية زائدة | WARN / FAIL | > 65% / > 78% |
| `blank` | عمل شبه فارغ | FAIL | < 8 ألوان |
| `palette-creep` | تسرّب عائلات لونية | WARN | > 3 عائلات |
| `focal-ambiguity` | لونان يتقاسمان الحصة | WARN | حصة متقاربة بلا مهيمن (~60%) |
| `edge-spill` | حبر يلامس الحافة | NOTE إن كان مقصودًا (bleed) / WARN | خارج الهامش |
| `unbalanced` | انحياز كتلة الحبر جهة | NOTE | > نصف الحبر جهة واحدة |
| `off-focal` | مركز الثقل بعيد عن نقطة التركيز | NOTE | مسافة عن ثُلث الإطار |
| `align-drift` | انحراف عن خط المحاذاة المشترك | WARN | انحراف عن خط الوسيط |
| `font-fallback` | خط لم يُطبَّق في البيئة | NOTE | قيست على خط البديل |
| `size-guard` | مقاس صغير جدًا | NOTE | أصغر ضلع < 360px |
| `asset-missing` | إطار بلا صورة | NOTE | صندوق داكن مُصرَّح به |
| `low-res` | دقة صورة أقل من 2× | NOTE | < احتياج التصدير |
| `frame-crop` | نسبة صورة ≠ نسبة الصندوق | NOTE | قصّ كبير عند cover |
| `export-integrity` | SVG الناتج تالف/ناقص النصوص | FAIL | تحقّق بعد البناء (بما فيه هروب `&`) |

## 4. فروع الإصلاح `applyFixes`

كل فرع يمرّر `locked()` ويكتب فعلته في السجل:

| الفرع | الفعل |
|---|---|
| ضمان التسلسل | تكبير العنوان حتى نسبة ≥ 1.6 |
| تباين النص | تغيير لون النص إلى أقرب قراءة ≥ 4.5:1 |
| المنطقة الآمنة | سحب العناصر الزائدة للداخل — مع «تُرك N مقفلًا» |
| محاذاة | ضبط N عنصرًا إلى خط اليد الوسيط |
| فيض النص | تصغير الحجم خطوةً حتى يدخل سطره الصندوق |
| تفكيك التداخل | إنزال المكوّن الأقل تحت الأعلى بفجوة، أو رفع الأعلى، ثم ضغطه إن دفعه النقل خارج القاع |
| المقفل | رسالة صادقة بدل التعديل — ويفشل الحل صراحةً إن كان القفل هو السبب |

## 5. المراقب `critic()` — 8 معايير مرجَّحة

| المعيار | مربوط بفحص |
|---|---|
| التباين | `low-contrast` |
| التسلسل | `weak-hierarchy` |
| التوازن | `unbalanced` |
| المساحة السالبة | `clutter` · `blank` |
| تماسك الألوان | `palette-creep` · `focal-ambiguity` |
| سلامة الحافة | `edge-spill` · `text-overflow` · `layer-overlap` |
| نقطة التركيز | `off-focal` |
| سلامة المخرج | `export-integrity` · `asset-missing` · `font-fallback` · `low-res` · `frame-crop` · `size-guard` |

- **أوزان حسب النوع** — كل نوع وله ما يعيش أو يموت عليه: مصغّرة تباين 1.7 (تُقرأ عند 160px) · لافتة تسلسل 1.6 (تُقرأ من بعيد) · بطاقة اقتباس توازن 1.5 · قائمة طعام مساحة سالبة 1.4 · قصة سلامة حافة 1.5 · إعلان منتج تباين 1.5.
- **الدرجة** 0–100 من الأوزان × الملاحظات، مع **أولوية إصلاح = الفجوة × الوزن** — يُعرض أول سطر في لوحة النقد.
- فقير مُصنَّع → «مقبول ٥٠» — الدرجة لا تُكذب.

## 6. طبقات الذكاء الأخرى

| الطبقة | الملف | ماذا تضيف |
|---|---|---|
| معرفة تُطبَّق | `knowledge.js` | مبادئ وقواعد (`KNOWLEDGE_APPLIERS`) تُعدّل الخطة مباشرة وتسجّل «ما تغيّر فعلًا» في `knowledgeApplied` — تُطبَّق قبل القياس **و** بعد كل إصلاح |
| موجز إبداعي | `creative.js` | تحليل وصف حر إلى 12 حقلًا (علامة · جمهور · هدف · رسالة · نبرة · مزاج · قناة · تميّز · قيود · مخرجات · مراجع) — **الحقل غير المذكور يبقى فارغًا ولا يُخترع**، ويُحرَّر ويُحفظ |
| مراجع | `knowledge.js` | `DESIGN_REFS` كـ«بقعة» على الخطة مع مبرّر — لا نسخ تصاميم |
| أنواع وأشكال | `knowledge.js` | `DESIGN_GENRES` (بنية تخطيط مميّزة) و`DESIGN_SHAPES` — تُغذّي المخطّط |
| تعديل المصمّم | `app.js` | `overrides`: color · opacity · sizeF · weight · align · hidden · dx · dy · sw · sh · locked · `__order` — **الأعلى ترتيبًا فوق كل ما سبق** |
| قياسات الفاحص | `inspector.js` | لوحة `#inspMeasure`: صندوق · حواف · ترتيب رسم · تسلسل · محاذاة · تباعد · تداخل (أبعاد لا مساحة) · طباعة · قياس سطر · حالة |

## 7. خط الأساس القابل للتكرار

- مصفوفة **60 تركيبة** (10 أنواع × 3 تكوينات × 2 أسلوب) بـ`autoFix:false` → **0 تحذير/0 خطأ**.
- خط الأساس بإصلاح تلقائي → «نظيف · ملاحظات» · صفر أخطاء console · `pytest 15/15`.
- أي رقم في هذا المستند من اختبار حيّ لا من الذاكرة.
