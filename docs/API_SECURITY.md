# API_SECURITY — أمن المفاتيح والبيانات في مِرسم

> مُراجَع ومُتحقَّق منه من الكود نفسه (2026-11-11). كل ادعاء هنا قابل للتحقق بأمر واحد مذكور في القسم الأخير.

## 1. المبدأ الحاكم

**كل شيء محلي افتراضيًا.** مِرسم يشتغل بالكامل بلا أي مفتاح ولا حساب ولا خادم:
تحليل الوصف، المخطّط، الرسم، القياس، الإصلاح، النقد، التصدير بكل صوغه — كلها في متصفحك.

**المفاتيح اختيارية تمامًا.** إن أردت مزوّدًا نصّيًا (Gemini/OpenAI) أو محرّك صور، فتضع مفتاحك أنت في حقل بالواجهة، ويُحفظ في `localStorage` على جهازك، ولا يُستعمل إلا حين تضغط زرًا تختاره بنفسه.

## 2. فحص الكود — حقائق

| الفحص | النتيجة |
|---|---|
| أنماط مفاتيح حقيقية (`sk-…` · `AIza…` · `ghp_…` · `AKIA…` · `Bearer …`) في كل المستودع | **0 تطابق** |
| المكان الوحيد المشابه | نصّ placeholder داخل حقل إدخال المستخدم في `index.html` (`sk-… / AIza…`) — ليس مفتاحًا، بل تلميح للمستخدم |
| ملفات `.env` أو تكوين فيه سرّ | **لا شيء** |
| خادم وسيط يستقبل مفاتيح | **لا يوجد** (النشر ملفات ثابتة على Vercel — انظر «حدود معروفة») |
| CDN خارجي | **لا شيء** — كل المكتبات والخطوط في `web/vendor/` محليًا |

> التحقق: `git grep -E "sk-[A-Za-z0-9]{20}|AIza[A-Za-z0-9_-]{30}|ghp_[A-Za-z0-9]{30}|AKIA[A-Z0-9]{12}"` → صفر.

## 3. مفاتيح `localStorage` التسعة

### مفاتيح فيها مفاتيح/إعدادات اختيارية (تغادر الجهاز عند طلبك أنت فقط)

| المفتاح | المحتوى | يُقرأ في | إلى أين يصل؟ |
|---|---|---|---|
| `mirsam.ai` | إعدادات المزوّد النصّي: المزوّد · النموذج · المفتاح · نقطة نهاية مخصّصة | `knowledge.js` | **إلى المزوّد نفسه فقط**، وعند نداء صريح منك: Gemini عبر `generativelanguage.googleapis.com` (المفتاح في سطر الـURL) · OpenAI عبر `api.openai.com` مع ترويسة `Authorization` · مخصّص عبر عنوانك أنت |
| `mirsam.engine` | محرّك الصور: نقطة النهاية + الرمز | `studio.js` | **إلى نقطة النهاية التي هيّأتها أنت فقط** (freefield/ComfyUI) — والمحرّك الأصلي لا يحتاجها |

### مفاتيح بيانات تصميم (لا تغادر المتصفح أبدًا)

| المفتاح | المحتوى |
|---|---|
| `mirsam.overrides` | تعديلات المصمّم على الطبقات: لون · شفافية · حجم · وزن · محاذاة · إخفاء · قفل · موضع `dx·dy` · أبعاد `sw·sh` · ترتيب `__order` |
| `mirsam.frame` · `mirsam.qr` · `mirsam.icon` | وسائط موضعية (صورة إطار · رمز QR · أيقونة) — تُرفع من جهازك وتبقى عليه |
| `mirsam.creativeBrief` | الموجز الإبداعي (12 حقلًا) بعد تحليله وتحريره |
| `mirsam.knowledge` | مدخلات المعرفة التي أضفتها يدويًا |
| `mirsam.refLibrary` | مكتبتك الشخصية من المراجع |

## 4. تفسير `localStorage` — ما تعنيه أمنيًا

| الحقيقة | ماذا تعني |
|---|---|
| تخزين **حسب أصل الموقع** | ما تحفظه مِرسم على `ai-design-agent-gules.vercel.app` لا يراه موقع آخر، وما تحفظه محليًا (`127.0.0.1`) لا يصل الإنتاج |
| **لا يُرسل تلقائيًا** مع أي طلب | المتصفح لا يرفق `localStorage` بأي نداء؛ الإرسال يتم فقط لأن كود مِرسم يضعه صراحة في استدعاء `fetch` (المفتاح فقط، وعند النداء الذي اخترته) |
| **مقروء لكل جافاسكربت على نفس الأصل** | هذا هو حدّ التهديد: اختراق XSS في نفس الموقع = قراءة مفاتيحك المحفوظة. لهذا لا يوضع فيها سرّ افتراضيًا — المفتاح اختياري وبقرارك |
| لا يُشارك بين المواقع ولا بين الأجهزة | مفتاحك على جهازك وحده؛ نسخة المتصفح (sync) سلوك المتصفح لا مِرسم |
| مسحه يدوي | أدوات المتصفح ← Application ← Local Storage، أو أزرار «إعادة الضبط» في الواجهة |

**إذا شاركت رابط الموقع مع غيرك:** يشارك واجهة مِرسم فقط — مفاتيحك في `localStorage` على جهازهم فارغ.

## 5. جدول نداءات الشبكة الكامل

كل نداء في التطبيق، ولماذا، وماذا يحدث لو فشل:

| # | النداء | الملف | متى يُرسل؟ | اختياري؟ | عند الفشل |
|---|---|---|---|---|---|
| 1 | `POST generativelanguage.googleapis.com` (Gemini) أو `api.openai.com` أو نقطة نهاية مخصّصة | `knowledge.js` | زر «تحليل محلي بالذكاء الاصطناعي» بوجود مفتاح | ✅ اختياري | رسالة صريحة + **البديل الكلي: المحلّل المحلي `parseBriefPrompt`** الذي يعمل بلا شبكة أصلًا |
| 2 | نقطة نهاية محرّك الصور (freefield / ComfyUI) | `knowledge.js` | عند طلب توليد صورة بمحرّك خارجي | ✅ اختياري | رسالة صريحة — لا شيء يعطّل |
| 3 | `api.openverse.org/v1/images` (بحث صور تجارية مرخّصة) | `studio.js` | زر البحث في المراجع | ✅ اختياري | رسالة صريحة + **البديل: رفع صورة من جهازك** |
| 4 | `api.github.com` + `raw.githubusercontent.com` (فحص وجود إصدار أحدث لـfreefield) | `knowledge.js` | عند فتح قسم المحرّك | ✅ اختياري | تُخفى ملاحظة التحديث فقط — لا أثر على أي ميزة |
| 5 | `fetch` لخطوط `vendor/fonts/*.ttf` | `fonts.js` | تحميل الصفحة | ⛔ محلي (نفس الأصل) | خط النظام البديل + تنبيه `font-fallback` صادق في الفحص |

**كلها HTTPS.** لا نداء سادس. لا صورة ولا نص ولا مقياس يُرسل خارجًا في الوضع الافتراضي.

## 6. حدود معروفة — بلا تجميل

| الحد | السبب |
|---|---|
| **لا خادم وسيط للمفاتيح** | النشر ملفات ثابتة (لا serverless). وجود وسيط = تغيير بنية النشر، وهو مؤجَّل بقرار موثّق في `MIRSAM_UPGRADE_ROADMAP.md` لا بوعد |
| مفتاحك يظهر في شبكة المتصفح | نتيجة مباشرة لنداء المزوّد من المتصفح — من يرى شبكة جهازك يرى المفتاح. من لا يثق بذلك يستخدم تحليلًا محليًا (لا مفتاح أصلًا) |
| XSS في نفس الأصل = كشف `localStorage` | مُعالَج بإجراء معتاد: لا سكربتات خارجية، لا CDN، كل شيء من `vendor/` محلي ومقروء الرخص |

## 7. تحقّق بنفسك (أوامر حقيقية)

```powershell
# 1) لا مفاتيح في الكود
git grep -E "sk-[A-Za-z0-9]{20}|AIza[A-Za-z0-9_-]{30}|ghp_[A-Za-z0-9]{30}"   # ← صفر

# 2) كل نداءات fetch في الواجهة
git grep -n "fetch(" web/                                                    # ← 8 نداءات، كلها في الجدول أعلاه

# 3) كل مفاتيح localStorage
git grep -oh "mirsam\.[A-Za-z]*" web/ | Sort-Object -Unique                  # ← 9 مفاتيح، كلها في الجدول أعلاه

# 4) لا CDN
git grep -nE "https://cdn\.|unpkg\.com|jsdelivr" web/                        # ← صفر
```
