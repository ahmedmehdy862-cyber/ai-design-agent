# ASSET_LICENSES — أصول مِرسم ورخصها

> كل أصل في هذا المشروع إمّا **مفتوح الرخصة ومُنسَب**، أو **أصلي مُنتَج بالكود**. لا شيء بينهما. (مُتحقَّق منه: 2026-11-11)

## 1. الخطوط العربية — SIL OFL 1.1

| الخط | المصدر | الرخصة | الاستعمال في مِرسم |
|---|---|---|---|
| Cairo | github.com/google/fonts | SIL Open Font License 1.1 | خط العناوين/النظام الافتراضي |
| Tajawal | github.com/google/fonts | SIL OFL 1.1 | بديل عناوين |
| Almarai | github.com/google/fonts | SIL OFL 1.1 | بديل نصوص |
| Amiri | github.com/google/fonts | SIL OFL 1.1 | بديل تحريري |

- **الملفات:** 9 ملفات TTF في `web/vendor/fonts/` (1.66MB إجمالًا) — قُسِّمت بـ`fonttools` إلى نسختي عربي+لاتيني لتقليل الحجم.
- **الاستعمال:** `fonts.js` يسجّلها في `document.fonts` لقياس النص الحقيقي، ويضمّنها base64 داخل SVG عند التصدير (لأن صورة SVG لا تحمّل خطوط الصفحة).
- **التضمين في المخرجات مسموح** صراحةً بترخيص OFL (الخط المضمَّن جزء من المستند المرسل، وهذا استعمال مقصود للترخيص).
- خطوط النظام (Segoe UI · Tahoma · Arial) البديلة: ترخيص نظامك، تُستعمل فقط إن غاب الخط المحلي (والفحص يصرّح بـ`font-fallback` حينها).

- شروط MIT: الإبقاء على إشعار الرخيص — مضمون هنا وفي ترويسة كل ملف.

## 3. الصور — Openverse (للبحث فقط)

| البند | القاعدة المطبَّقة |
|---|---|
| المصدر | `api.openverse.org` — بحث **بمرشّح `license_type=commercial` فقط** |
| الرخص المسموحة | CC0 · PDM (ملكية عامة) · CC BY · CC BY-SA — كلها تجارية وإعادة استعمال |
| الإسناد | كل نتيجة تعرض **الرخصة والمُصوِّر** في الواجهة، والائتمان الكامل (`title · creator · license · url · source`) يُحفظ مع الصورة في الوسائط ويظهر في لوحة الميديا |
| ما لا يُستخدم | **Behance وDribbble**: لا API رسمية + حظر صريح في تعليمات المشروع (لا scraping لمصادر محمية) |
| البديل | رفع صورة من جهازك — بلا نداء شبكة أصلًا |

## 4. الأصول الأصلية — بلا ترخيص خارجي

| الأصل | كيف أُنتج |
|---|---|
| كل التصاميم المخرَّجة (SVG/PNG/PDF/PSD/GIF/WebM) | مرسومة برمجيًا من `makePlan` → `renderSVG` — أشكال ونصوص مولَّدة، ملك استخدامك الكامل |
| الرموز/الطبقات/التذييل (`rationale`) | مكتوبة قانونيًا داخل `knowledge.js` + `app.js` |
| المراجع المصوّرة | تُشاهَد وتُلهَم (تعديل «patch» على الخطة) — **لا يُنسخ أي ملف** ولا يُقتبس تصميم حرفيًا |
| الأيقونات المضمنة في التصدير | من tabler-icons (MIT) أو مرسومة برمجيًا |

## 5. التزام النشر

1. نشر GitHub + Vercel ينطوي على الملفات كما هي — ورخص MIT/OFL تسمح بالنشر كما فعلنا مع إبقاء الإشعارات (هذا الملف + ترويسات `vendor/`).
2. المخرجات التي تضمّن خطوطًا (PDF/SVG) تُرسل الخط المضمَّن بترخيصه — استعمال مرخَّص بـOFL.
3. صورة Openverse تُنشر مع ائتمانها المحفوظ في البيانات الوصفية للوسائط.
4. أي أصل جديد يجب أن يدخل بقسم في هذا الملف قبل نشره — إن لم تُعرَف رخصته، لا يُنشر.
