# مراجعة تكامل المستودعات — Phase 3

> فحص **قبل أي تركيب**، بتاريخ ٢٠٢٦-١١-١٤، عبر GitHub API (قراءة فقط: `gh api`).
> **لم يُثبَّت أي شيء جديد** في هذه المراجعة. كل رقم هنا مقروء من المستودع نفسه، لا من وصف تسويقي.

## 1. البوابة (كل بند مفروض على كل مستودع)

| # | الفحص | كيف فُحص |
|---|---|---|
| 1 | الترخيص | `repos/{r}` + نص `LICENSE` |
| 2 | آخر نشاط | آخر commit + `pushed_at` + `archived` |
| 3 | المشكلات المفتوحة | `issues?state=open` (وعزل طلبات الدمج) |
| 4 | الاعتماديات | `package.json` → `dependencies` |
| 5 | سكربتات التركيب | مفاتيح `scripts` التي تعمل عند `npm install` |
| 6 | مخاطر التنفيذ/الحقن | هل يشغّل أوامر أو يكتب ملفات؟ هل يقبل مسارات من الخارج؟ |
| 7 | تداخل الوظائف | هل يضيف قدرة لا موجودة، أم يكرّرها؟ |
| 8 | النقل (MCP/HTTP) | stdio · HTTP · استدعاء مباشر |

## 2. النتائج

### أ) `ie3jp/illustrator-mcp-server` — **مقبول تقنيًا · مرفوض للتركيب الآن**

| البند | النتيجة |
|---|---|
| الترخيص | MIT (نص `LICENSE` صريح) |
| النشاط | commit أخير 2026‑11‑11 · v1.14.0 · غير مؤرشف · 226 ⭐ |
| المشكلات | 3 مفتوحة، **كلها طلبات دمج** (لا عطل مفتوح) |
| الاعتماديات | 2 فقط: `@modelcontextprotocol/sdk` · `p-limit` · Node ≥ 20 |
| سكربتات التركيب | `prepublishOnly` فقط — **لا يعمل عند تركيب الحزمة** |
| مخاطر التنفيذ | يكتب `script-{uuid}.jsx` و`run-{uuid}.ps1` ثم ينفّذهما: `powershell.exe` → `Illustrator.DoJavaScript`. أي أنه **سطح تنفيذ أوامر/سكربت** بصلاحية المستخدم |
| النقل | MCP عبر stdio (٦٣ أداة) — عملية محلية دائمة |
| التداخل | يكرّر جزء «التصدير إلى تطبيق Adobe» الذي يغطّيه جسرنا الرفيع، ويضيف تحكّمًا حيًّا لا نحتاجه |
| التوافق | Illustrator 2024+ (المثبَّت هنا 2025) — متوافق |

**القرار:** البوابة ناجحة (ترخيص/نشاط/اعتماديات نظيفة)، لكن **لا حاجة وظيفية تبرّر التركيب**: التطبيق يصدّر SVG/PSD/PDF محليًا، والجسر يكتب PSD على القرص. تركيبه يضيف عملية MCP دائمة + مسار تنفيذ PowerShell/JSX + سطح هجوم، مقابل قدرة غير مطلوبة. **يُترك كخيار موثّق، لا يُثبَّت تلقائيًا.**

### ب) `neuregex/freefield` — **مقبول كخيار خارجي عبر HTTP فقط**

| البند | النتيجة |
|---|---|
| الترخيص | MIT · 1355 ⭐ · غير مؤرشف |
| النشاط | commit أخير 2026‑11‑06 · 5 مشكلات (طلبات ميزات لا أعطال) |
| الاعتماديات | Python/ComfyUI (`@comfyorg/sdk`, `ajv` لواجهة Node) · 144MB |
| مخاطر التنفيذ | لا شيء عندنا: **لا ننسخ كوده ولا نثبّته**. التطبيق يكلّم نقطة نهاية HTTP يضبطها المستخدم (`sendToEngine`) |
| التداخل | لا تداخل — هو محرّك صور اختياري، وليس مصمّمًا |
| حدود يجب قولها | النماذج داخله لها تراخيصها الخاصة (مثل MiniMax‑Music3 Community License)؛ ما يولّده المستخدم يخضع لترخيص النموذج، لا لـMIT الخاص بالمستودع |

**القرار:** **مقبول** بصيغته الحالية: تكامل HTTP اختياري، بلا تركيب وبلا كود محلي. لا نضيف اعتمادية.

### ج) `Agamnentzar/ag-psd` — **مقبول (مُستخدَم أصلًا)**

| البند | النتيجة |
|---|---|
| الترخيص | **MIT** (نص `LICENSE`: “The MIT License (MIT)” — تصنيف GitHub `NOASSERTION` سببه صياغة الملف فقط) |
| النشاط | commit أخير 2026‑11‑11 · v34.2.0 · 743 ⭐ · 54 مشكلة مفتوحة (معظمها أسئلة توافق نص/خطوط) |
| الاعتماديات | `base64-js` · `pako` · سكربت تركيب: `prepublishOnly` فقط |
| الاستخدام عندنا | `web/vendor/ag-psd.js` (نسخة مثبّتة في المستودع) — تصدير PSD والجسر |
| مخاطر | يقرأ ملفات PSD من المستخدم فقط؛ لا تنفيذ أوامر |

**القرار:** **مقبول** — مستخدم ومثبَّت مسبقًا، ومراجعة ترخيصه تؤكد MIT. لا ترقية الآن (لا حاجة، والترقية تغيّر سلوك الطبقات).

### د) `Hopding/pdf-lib` — **مقبول مع تحفّظ (مُستخدَم أصلًا)**

| البند | النتيجة |
|---|---|
| الترخيص | MIT · 8677 ⭐ |
| النشاط | **شبه خامل**: آخر commit 2021‑11، آخر `pushed_at` 2024‑07 · 319 مشكلة مفتوحة |
| الاعتماديات | `@pdf-lib/standard-fonts` · `@pdf-lib/upng` · `pako` · `tslib` · بلا سكربتات تركيب |
| الاستخدام عندنا | `web/vendor/pdf-lib.min.js` — **إنشاء** صفحة PDF من صورة PNG فقط |
| مخاطر | لا تحليل PDF من مصادر غير موثوقة عندنا؛ الاستخدام كتابة فقط |

**القرار:** **مقبول مع تحفّظ موثَّق**: خامل وكثير المشكلات، لكن سطح استخدامنا ضيّق (صفحة واحدة + صورة مضمّنة) ومُختبَر (MediaBox والرَستر 2/2). لا ترقية عمياء ولا توسيع للاستخدام.
