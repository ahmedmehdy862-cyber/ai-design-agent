# مِرسم — AI Design Agent

وكيل تصميم جرافيكي **يعمل بالقياس لا بالتخمين**: يقرأ الوصف، يبني خطة تصميم، يعرضها SVG، يقيس النتيجة بكسل بكسل، ثم يصحّحها ذاتيًا — **كله داخل متصفحك، بلا خادم وبلا مفاتيح API**.

> الموقع ثابت بالكامل: خصّه على Vercel واعرضه محليًا أثناء التطوير.

**🌐 الموقع الحيّ (Vercel):** https://ai-design-agent-gules.vercel.app
**📦 المصدر (GitHub):** https://github.com/ahmedmehdy862-cyber/ai-design-agent

## لماذا «مِرسم»؟

معظم أدوات التوليد تُخرج صورة وتصمت. «مِرسم» يُخرج **مخرجًا قابلًا للقياس والتعديل**:

1. **موجز** ← يُفهم محليًا (نوع التصميم، المقاس، المزاج، شكل العناصر، الزر، التاريخ، البنود).
2. **خطة** ← عناصر مرقّمة (طبقات) بإحداثيات وألوان وأوزان وسلّم مسافات.
3. **عرض** ← SVG متجهي مبني من الخطة (RTL صحيح للنص العربي).
4. **قياس** ← تباين WCAG، كثافة الحبر، التوازن، التسلسل، العائلات اللونية، بكسلات التجاوز.
5. **تصحيح** ← حلقة حتى ٣ محاولات للعيوب ذات الإصلاح الحتمي فقط (والتي لا تُصلَح تُعرض ملاحظة).
6. **تسليم** ← حسب البرنامج المستلم: طبقات + إطارات + أدلة استيراد.

### ما الجديد في الواجهة

- **فاحص الطبقات**: كل عنصر على حدة — لون · شفافية · حجم · وزن · محاذاة · إخفاء — **والتعديلات تبقى بعد إعادة التوليد** (تتغلّب حتى على التصحيح التلقائي).
- **منزلق المسافة بين النصوص** (٦٠٪–٢٢٠٪) + اختيار عائلة الخط.
- **كاروسيل**: تقسيم الوصف إلى شرائح (غلاف + بنود + دعوة)، شريط مصغّرات، تنقّل، وتنزيل دفعة واحدة مع `mirsam-carousel.json`.
- **استوديو ميديا**: تحويل المقاس، فيديو **WebM** من الشرائح بتلاشٍ ناعم، خطة محتوى Markdown.
- **المعرفة تُنتِج**: مبادئ التصميم ونظرية الألوان قواعد تُنفَّذ داخل المخطّط قبل القياس، ويُبلَّغ عمّا تغيّر فعلًا.
- **المراجع كإخراج فني**: الوصف يختار مرجعًا (فخم/تقني/تحريري…) فيُطبَّق باليتته وتوزيعه فورًا.
- **اختصارات**: `G` توليد · `E` PNG · `V` SVG · `R` تنويع · `←→` الشرائح · `1–5` طبقات التغذية · `؟` القائمة.
- **تحديد بالنقر**: اضغط أي عنصر في المعاينة ليُضيء صفّه في الفاحص.

## التشغيل محليًا

```bash
# الواجهة (ثابتة بالكامل)
cd web
python -m http.server 8137
# → http://127.0.0.1:8137/

# المحرك بايثون (QA + مخطّط) واختباراته
pip install -r requirements.txt
python -m pytest tests/unit -q
```

يتطلب محرك القياس **ImageMagick 7** (`magick` في PATH، أو متغيّر بيئة `MAGICK`).

## النشر

### Vercel (رابط عرض فوري)

**مُنشَر فعليًا:** https://ai-design-agent-gules.vercel.app

```bash
npm i -g vercel
vercel login
vercel --prod        # vercel.json يضبط outputDirectory = web + framework = null
```

ملاحظات تشغيل:
- `.vercelignore` يمنع رفع `workspace/` ومحرك بايثون (الموقع ثابت فقط) — بدونه يفشل الرفع بحجم ~6MB أو بحث Vercel عن مدخل Python.
- إن ظهر خطأ `No python entrypoint found` فتأكد أن `framework: null` و`buildCommand: ""` في `vercel.json`.

### GitHub (المصدر والاختبارات)

```bash
git init
gh repo create ai-design-agent --public --source . --push
```

CI (`.github/workflows/ci.yml`) يشغّل اختبارات بايثون + فحص صياغة JS مع كل دفعة.

> **حالة CI:** الملف موجود في المستودع محليًا فقط — رمز GitHub الحالي بلا نطاق `workflow` فيمنع الدفع. للتفعيل: `gh auth refresh -h github.com -s workflow` ثم أدخل الرمز على https://github.com/login/device ثم `git push origin main`.

## قواعد ثابتة (لا تُساوَم)

- **٠ خادم · ٠ مفتاح**: كل شيء محلي افتراضيًا؛ المفاتيح اختيارية وتُحفظ في `localStorage` فقط.
- **لا ادعاء قبل التحقق**: كل رقم في الواجهة مقيس فعليًا من بكسلات المخرج.
- **فصل القياس عن الذوق**: القياس موضوعي (رقم)، والمراجعة الجمالية ملاحظة معلَّمة `NOTE`.
- **الحد الأقصى للمعرفة**: المخرج يبقى من إنتاج المخطّط المحلي، لا صورًا مولَّدة.
